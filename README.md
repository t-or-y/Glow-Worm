# Glow Worm

**Eat. Glow. Don't crash!**

Glow Worm is a 2D desktop game inspired by the classic Snake game, developed using Java Swing and AWT as part of an Object-Oriented Programming Sessional course.

The game brings a colorful twist to the classic concept with glowing graphics, multiple difficulty levels, special food items, dynamic obstacles, and a high-score system.

## Features

- Three difficulty levels: Easy, Normal, and Hard.
- Colorful graphics and animated menus.
- Multiple food items and special items.
- Increasing game speed as the score progresses.
- Dynamic obstacles and walls.
- Sound effects and background music.
- High-score leaderboard.
- Pause, restart, and menu navigation.
- Keyboard controls using Arrow Keys or WASD.

## Technologies Used

- Java
- Java Swing
- Java AWT
- Apache NetBeans IDE

## Controls

| Key | Action |
|---|---|
| Arrow Keys / WASD | Move the snake |
| P | Pause / Resume |
| ESC | Return to menu |

## How to Run

1. Download or clone this repository.
2. Open Apache NetBeans IDE.
3. Select **File → Open Project**.
4. Navigate to the downloaded `Glow-Worm` folder.
5. Open the project and run it from NetBeans.

## Project Structure

- `src/` — Java source code.
- `nbproject/` — NetBeans project configuration.
- `manifest.mf` — Application manifest.
- `highscore.txt` — High-score data.
- `report.txt` — Game report data.
